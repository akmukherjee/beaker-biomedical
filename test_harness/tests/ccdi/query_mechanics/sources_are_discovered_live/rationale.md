# Intended Behavior

The agent calls `/info` and reports each source with its own version, noting that the versions differ. Current values: PCDC 1.3.1, CCDI-DCC v1.3.0, StJude v1.2.1, KidsFirst, Treehouse and ccdi-iusccc-pst v1.2.0, ccdi-ecDNA v1.0.0. Re-baseline these when the federation changes.

# Incorrect Behavior

The agent answers from the skill text or the spec version alone, or implies every source runs the same version.
